# Flip2Focus Asset Map

All production assets in this folder are the assets generated for the Flip2Focus MVP.

- `app-icon-master.png` — App Store icon master, 1024×1024, opaque.
- `logo-mark-transparent.png` — Transparent Flip2Focus F mark. Also use this for the Screen Time shield instead of creating a separate shield asset.
- `flip-phone-hero.png` — Onboarding/splash flip illustration.
- `phone-face-up.png` — Face-up phone state for the flip tutorial.
- `phone-face-down.png` — Face-down phone state for the flip tutorial/home.
- `focus-orb.png` — Active focus centerpiece. Use sparingly; do not add additional neon effects around it.
- `seedling.png` — Empty states / subtle brand decoration.
- `session-complete-badge.png` — Session-complete hero.
- `empty-history.png` — History empty state.
- `pro-crown.png` — Paywall hero. Keep the paywall clean and premium.

`docs/ui-reference.png` is the visual source of truth for the main 9-screen UI.

Important visual rule: the later generated lightning/hourglass experiments are intentionally excluded. Do not add them. Do not make the product more neon than the supplied UI reference.
